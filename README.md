### Recommended Installation

1. Save the textbox.html somewhere.
2. Open it in your web browser, and bookmark
3. Make sure that Yomitan (or whatever extension you're using) has permissions for viewing local files enabled.
4. Paste text and scan!

### Features

* Fast, no graphics library or network requests made
* Input text is saved in browser storage. If you accidentally close the tab, you can reopen it and your text will still be there. The contents are deleted when your browser is closed entirely.
